# 🐱 Cat vs Dog Classifier 🐶

A Deep Learning project that classifies an image as either a cat or a dog.

## 🚀 Technologies Used

- Python
- TensorFlow / Keras
- Streamlit
- NumPy
- Pillow
- Matplotlib

## 📂 Project Structure

- `dataset/` - Cat and dog training images
- `train.py` - Trains the Deep Learning model
- `cat_dog_model.keras` - Trained model
- `app.py` - Streamlit application
- `requirements.txt` - Required Python libraries

## ▶️ How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
